# 绿植租赁管理系统
## 技术栈
Vue3 + Vite + Element Plus + Axios + SpringBoot + MySQL

## 项目简介
本项目是一套面向绿植商家与用户的租赁管理后台系统，分为用户端与管理端。系统支持绿植展示、在线租赁、订单管理、费用结算、用户权限管理、绿植库存管理等核心业务，实现绿植租赁业务全流程线上化管理。

## 主要功能
1. 独立完成前台用户页面（绿植首页、分类筛选、租赁详情、购物车、下单结算、订单中心）与后台管理页面（绿植管理、库存、订单审核、用户权限、数据统计）的全部开发。
2. 封装表格、分页、搜索、图片上传等通用组件，对接后端全部接口，完成前后端联调。
3. 对图片做懒加载与压缩优化，高频搜索与滚动事件添加防抖节流，提升页面流畅度。

## 项目收获
熟练掌握Vue3全套业务开发流程，具备独立完成前后端分离项目前端开发、接口对接、组件封装与简单性能优化的能力，熟悉真实后台系统的业务逻辑与开发规范。
